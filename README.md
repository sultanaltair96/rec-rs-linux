# rec-rs-linux

An independent Linux port of [rec-rs](https://github.com/michaelshimeles/rec-rs), a macOS screen and camera recorder.

The goal is feature parity with the upstream application, distributed for Linux as a Flatpak and/or AppImage. This project is in its initial planning stage: no Linux application or packages are available yet.
